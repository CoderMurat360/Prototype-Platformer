# Prototype Platformer

A template platformer game made in Raylib.

---

## Requirements

You need all three:

- C++ compiler (C++17 or newer)
- CMake 3.20+
- raylib 

---

## Controls
- **A / D** – Move left / right
- **Space** – Jump

---

## Notes
- The .vscode folder is optional and only for VS Code users
